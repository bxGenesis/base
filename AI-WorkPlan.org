*Where.* Yes: =bxObjects/bro_dockerfiles= (the images, =containerManage.sh=), and

bro_dockerfiles' =README.org= ("VNC password (optional)"); its AI-DevStatus lists VNC passwords as
untested on a daemon --- this VM run is the first.

*How it works.* No password is the default. =set= asks twice, makes the password file with the
image's own =vncpasswd -f= in a *throw-away container of the image* (never in the running instance;
the password on stdin), =docker cp='s it into the instance as =/home/bystar/.config/bisosVncPasswd=,
and restarts a running instance. At each VNC start =/usr/local/bin/vncStart.sh= makes the file
bystar's (0600) and runs =vncserver -SecurityTypes VncAuth -rfbauth= (empty or missing file: none).
Lost on =delete=.

*Cause found (on the VM, 2026-11-23).* "vncpasswd produced no output": =which -a vncpasswd= is empty
in the container. The confined Dockerfiles install =tigervnc-standalone-server tigervnc-common= with
=--no-install-recommends=; =vncpasswd= is in =tigervnc-tools=. Installing it in the running instance
does not help, since =set= runs the image, not the instance.

*Fixed (committed: bro_dockerfiles =f74525b=, dockerProc =045ac32=; not yet built):*
- bro_dockerfiles: =tigervnc-tools= in the VNC install of =bisos_deb13-fresh= and =bisos_deb12-fresh=

*The decision (2026-11-24): a bootstrap sbom per CBM leaf.* Each leaf in a =bro_= repo gets
=cbmBootstrap-sbom.pcs= (name to confirm; the leaf's directory says which capability), which
1) pip-installs the CBM's packages and 2) git-clones the CBM's repos. A leaf is then self-contained
and the CBMs fully distributed: what a capability needs before its CBS can run is in its leaf, not
in the platform's clone registry.

The leaves, by what their bootstrap does:

| Kind                  | Leaves                                                                 | Bootstrap                                        |
|-----------------------+------------------------------------------------------------------------+--------------------------------------------------|
| CBS in a pip package  | nginx, reactPlus (=bisos.webCap=), airflow, kafka, prometheus, grafana, pypiserver, devpi, geneweb | pip =bisos.<cap>= into =bisos3=; =cbsSpec= becomes a basename (PATH) |
| CBS in a repo         | csPlayerPerf, csPlayerUi, astroStarter, gatsbyBxSidebar (=bisos-web=)    | git clone of the site repo; its pip packages, if any |
| CBS in the bro_ repo  | platform (=bro_rawBisos/.../web/astro=)                                | none                                             |

Facts that shape it:
- bisos.sbom has no git kind: =bisos/sbom/reposSeed.py= is an empty stub. =pkgsSeed.setup()= has
  =aptPkgsList=, =pipPkgsList=, =pipxPkgsList=, =npmPkgsList=, =sbomsList= and =virtenv= (the bootstrap
  sets =virtenv="/bisos/venv/py3/bisos3"=).
