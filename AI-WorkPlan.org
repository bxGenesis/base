  =blee/base= are already like that here); =bisos-pip/.github= becomes a second clone of the repo the
  directory already is. Recommended: accept it for this stage, and add a separate TODO to migrate an

- *D3. bisos-web and cliGui without base.* Create =bisos-web/base= and =cliGui/base= on GitHub (the

*** Decided (2026-11-22)

- D1: the gitGroup directory's fto files will be done differently; deferred.
- D2: no conversion of existing platforms. The target is that a platform is updated by
  re-installing it and re-running its CBMs, so old-layout platforms phase out; this stage makes that
  re-install reliable. An existing platform keeps working, inconsistent with a fresh one; re-running
  the registry on it nests =base= / =.github= clones inside the old clone (harmless, untracked).
  On a fresh install, every gitGroup directory --- =bisos-pip= included --- is a plain directory.
- D3: =bisos-web= and =cliGui= stay without =base=.
