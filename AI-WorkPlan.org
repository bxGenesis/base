*The decision (2026-11-24): a bootstrap sbom per CBM leaf.* Each leaf in a =bro_= repo gets
=cbmBootstrap-sbom.pcs= (the leaf's directory says which capability). It is built in two phases
(below): Phase 1 pip-installs the CBM's packages; Phase 2 also git-clones the CBM's repos. A leaf is
then self-contained and the CBMs fully distributed: what a capability needs before its CBS can run
is in its leaf, not in the platform's clone registry.
