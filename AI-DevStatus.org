* Key Design Decisions
- =emacs+py+tex= for =.gitignore=, not =emacs+py=: it keeps =*_archive= (=AI-WorkPlan.org_archive=) and
  does not ignore =lib/=, which =provisioners= tracks (=lib/bash/=).
- Stage 2 decisions (2.1): the fto files of a gitGroup directory are deferred (to be done
  differently); existing platforms are not converted --- a platform is updated by re-installing it
  and re-running its CBMs, so the old layout phases out; =bisos-web= and =cliGui= stay without =base=.
- The gitGroup link is relative (=command()= with =ln -sfn=), because the pbd's =symLink()= always
  makes an absolute one.
- 3.1.2 (2026-11-24, user decision): each CBM leaf carries its own bootstrap sbom, so CBMs are
  self-contained and distributed, not dependent on the platform's clone registry. bisos.sbom has no
  git kind yet (=reposSeed.py= is a stub). VNC: =vncPassword set= hashes in a throw-away container of
  the image, so a tool missing there cannot be fixed in the running instance.
